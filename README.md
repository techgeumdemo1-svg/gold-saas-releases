# Gold SaaS — desktop downloads

Installers for the Gold SaaS desktop app. Download the newest version from
[Releases](../../releases/latest):

| Computer | File |
| --- | --- |
| Mac with Apple silicon (M1, M2, M3…) | `Gold-SaaS-<version>-arm64.dmg` |
| Mac with an Intel processor, macOS 13 or later | `Gold-SaaS-<version>-intel.dmg` |
| Mac with an Intel processor, macOS 12 (Monterey) | `Gold-SaaS-<version>-intel-macos12.dmg` |
| Windows | `Gold-SaaS-Setup-<version>.exe` |

Not sure which Mac you have? Apple menu → About This Mac: "Chip" means Apple
silicon, "Processor" means Intel, and the macOS version is shown at the top.

Each release also carries `latest.json`, which the app reads to tell you when
a newer version is out.
